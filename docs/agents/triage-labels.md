# Triage labels

| 技能中的角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会继续处理 |

技能提到 triage role 时使用右侧完全相同的 label 字符串；若 GitHub 中的实际
标签词汇发生变化，应先更新本文件，避免创建同义重复标签。
